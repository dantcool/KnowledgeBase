The periodic table contains information of every element and organizes the elements according to their physical and chemical properties. 

Each entry represents a single element and contains
- elements chemical symbo
- atomic number
- averagne atomic weight 

The elements are arranged in vertical columns called groups and horizontal rows called periods.

Alkali metals - all shiny sloids that react vigorously with air,water and halogens(Group7A )
alkaline earth metals- metals that react with water to form alkaline solutions 
noble gases - least reactive elements in the periodic table.

Group 1A - alkali metals
Group 2A - alkaline earth metals
Group 6A - chalcogens
Group 7A - Halogens
Group 8A - Noble gases
