The **Emperical formula** of a compound is the simples whole number ratio of elements present in a compound. Determining the percent composition of each element in a compound can be used to determine the empirical formula 

# Example- Use percent composition to determine the Empirical Formula 

A solid compound is found to contain K, S, And O with the follwing percent composition
- K:41.09%
- S:33.70%
- O:25.22%

What is the empirical formula of this compound?

First we assume we have been given a 100g sample. Then we calculate the amount (in mols) of each element present and then use the relative amounts to determine the empirical formula fo the compound.  

$$41.09g\;K*\frac{1mol\;K}{39.098g}=1.051mol\;K$$

$$33.70g\;S*\frac{1mol\;S}{32.065g}=1.051mol\;S$$

$$25.22g\;O*\frac{1mol\;K}{15.999g}=1.576mol\;O$$

Then to determine the simples whole-number ratio of elements, Divide each by the smallest value 


$$\frac{1.051mol\;K}{1.051}=1.000mol\;K=1mol\;K$$
$$\frac{1.051mol\;S}{1.051}=1.000mol\;S=1mol\;S$$
$$\frac{1.576mol\;O}{1.051}=1.500mol\;O=1.5mol\;O$$
Recall the values 1.5 is the same as the fraction 3/2 we get this number by the fraction mole of O so to balance ,multiply all three by amounts by 2, the denominator, To express the ratio of elements as whole numbers. 

We get K2S2O3
