**Quantum numbers** -  a set of numbers with integer values that define the properties of an atomic orbital 

**Principal quantum number(n)** - the quantum number that describes the size and energy of the shell in which the orbital resides 
- The allowed values of n are positive integers

**angular momentum quantum number(l)** - indicates the shape of the orbital 
- for any given value of n, l can have values that range from 0 to (n-1)


| l   | Orbital Label |
| --- | ------------- |
| 0   | s             |
| 1   | p             |
| 2   | d             |
| 3   | f             |
beyond l=3 the orbitals are labeled alphebetically (l=4 is a g orbital)

**magnetic quantum number($m_t$)** - the quantum number related to an orbitals orientation in space 

For a specific value of l, $m_t$ can have values that range from -l to +l, For example when l=1 the possible values of $m_t$ are -1,0 and +1 meaning there are three p(l=1) orbital
