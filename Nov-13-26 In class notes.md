Machine learning Explained
_____________________________
Not everyone needs to know all tech details of AI but we should all understand what it: 
- does(basic principles)
- can do (potential)
- cannot do (limitations)

Traditionally, Computer programming has take a recipe approach (if/then/else logic), which often fails in real world situations because programmers cant anticipate all possibilities 

Machine learning is a sub field of AI that gives computers the ability to learn without being explicitly programmed 

The terms MC and AI are often used interchangeably today because most AI uses machine learning 

ML is the technology behind 
- chat bots
- predictive text 
- language translation apps/services 
- recommendations in netflix spotify etc
- how your social media feeds are curated and presented 
- autonomous vehicle 
- specialized computer programs(eg. that can diagnose medical conditions based on images)

AI is learning. It makes mistakes and can be frustrating to work with 
See AIwierdness.com 

The function/purpose of MC can be categorized as

Descriptive: MC uses data to explain or describe something 

Predictive: MC uses data to predict what is likely to happen (or user is like to desire) 

Prescriptive: MC uses data to make suggestions about what actions to take(or takes them for you) 

Training of MC has 3 subcategrories
____________________________
supervised: MC is trained using labeled datasets originally labeled by humans 

unsupervised : MC  looks for patterns in unlabeled data.It can often find oatterns that humans cannot 

Reinfocement: MC uses trial and error with a human created reward function. It learns over time based on feedback
