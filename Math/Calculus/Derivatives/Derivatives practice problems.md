# The definition of the Derivative 

Using the definition of the derivative find the derivative of the following functions 

## 1.$f(x)=6$
## Solution
plugging this into the definition we get 
$$lim_{h\rightarrow0}\frac{6-6}{h} = lim_{h\rightarrow0}\frac{0}{h} = lim_{h\rightarrow0}=0$$

so our derivative would be 
$$f'(x) = 0$$
since the output of the function is always going to be 6 the h from f(x+h) doesn't just disappear, its that changing the input doesn't change the constant output which is again 6. so for the top we get 6-6 and our bottom is h and since 0 divided by any non-zero number is exactly 0 the expression
simplifies into 0 giving us our answer.
