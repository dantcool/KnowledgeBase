in addition to sine, cosine and tangent the easy three we also have three more functions defined as 

$$\text{Secant sec t = }\frac{\text{}hypotenuse}{adjacent}$$
$$\text{Cosecant csc t } = \frac{\text{hypotenuse}}{\text{opposite}}$$
$$\text{ Cotangent cot t } = \frac{\text{adjacent}}{opposite}$$
seeing these definitions you can see that these functions are the reciprocals of the first three functions. 

| $$\text{sin t = }\frac{1}{\text{csc t}}$$ | $$\text{csc t =}\frac{1}{\text{sin t}}$$  |
| :---------------------------------------: | ----------------------------------------- |
| $$\text{cos t = }\frac{1}{\text{sec t}}$$ | $$\text{sec t = }\frac{1}{\text{cos t}}$$ |
| $$\text{tan t = }\frac{1}{\text{cot t}}$$ | $$\text{cot t = }\frac{1}{\text{tan t}}$$ |
