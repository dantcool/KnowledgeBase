# Python
## Variables
- meaningful name for a piece of data stored in memory 
- value can change during the execution of the program 
- **Define** with a name and initial value 
- **Assign** new values using equal sign ("=")
- Should be meaningful 
- may consist of letters, digits, and underscores but may not start with a digit or special character. 

## Keywords or reserved words
internally deifined keyowoard in python which u cannot use as variable names 
such as True,Class return, is, finally, false and more. 

## Data Types 
**Integers**- whole number that can be positive negative or zero.
**Float**- floating point number meaning that it has decimal places.
**String**- collection of characters enclosed with "" or ''.
**Boolean**- Data type with twopossible valuse **TRUE** or **FALSE**
Use `type(.)` to know the data type.

## Escape sequences
| Escape sequence | Meaning                                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------------------- |
| \n              | Newline. Move the screen cursor to the beginning of the next line                                             |
| \t              | Horizontal tab. Moves the screen cursor to the next tab stop.                                                 |
| \r              | Carriage reutrn. Move the screen cursor to the beginning of the current line; do not advance to the next line |
| \b              | Backspace. Move the screen cursor back one space                                                              |
| \\\             | Backlash. Print a backlash character                                                                          |
| \\"             | Double Quote. Print a double quote character                                                                  |
| \\'             | Single uote. Print a single quote character.                                                                  |
