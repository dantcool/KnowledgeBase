1. Anaconda platform (https://www.anaconda.com/): Anaconda distribution is an open-source Data Sci-
ence Distribution Development Platform. It includes Python 3 with over 1,500 data science packages
making it easy to manage libraries and dependencies. Available in Linux, Windows, and Mac OS X.
2. Jupyter (https://jupyter.org/): JupyterLab is a web-based interactive development environment for Ju-
pyter notebooks, code, and data. JupyterLab is flexible: Configure and arrange the user interface to sup-
port a wide range of workflows in data science, scientific computing, and machine learning.
